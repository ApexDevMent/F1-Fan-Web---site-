
PIT WALL — F1 Season 2026 Hub

A fan-made Formula 1 dashboard for the 2026 season (77th World Championship). Dark gaming aesthetic with motorsport-grade telemetry UI featuring red (Ferrari)/green (DRS zones)/amber (sprint weekends) accents. Built with vanilla JS + CSS animations.

Content & Features:

Teams Section — 11 constructors with driver lineups, titles, and contextual notes (Ferrari's 16 titles, McLaren leading hybrid era, Cadillac's debut)
Driver Grid — 22 drivers sorted by world championship wins; Hamilton holds 7-time record (first Ferrari season)
Race Calendar — 24 total races (2 cancelled: Bahrain, Saudi Arabia); each card shows round, circuit, date, track length
Track Modal — Interactive popups with detailed stats: turns, DRS zones, banking/direction, historical debut year, circuit-specific insights
Telemetry Hero — Real-time counter: 11 teams, 22 drivers, 22 races, 2 cancelled
Design/UX:

Custom cursor — Trailing glow effect (red spotlight) + neon dot
Per-card micro-interactions — Radial gradients follow mouse; subtle perspective tilt on hover
Glassmorphism nav — Sticky blur top bar
Grid background — Subtle grid texture overlay (opacity: 0.35)
Status badges — "Завершён" (completed), "Следующий" (next), "Впереди" (upcoming), "Отменён" (cancelled)
Tech:

Vanilla JS (no frameworks)
CSS Grid + Flexbox responsive
Intersection Observer pattern
Modal overlay with escape/click-outside handlers
Date parsing for race timeline logic
Vibe: Esports-meets-F1-data-viz; treats championship as gaming leaderboard with real stakes. Perfect for fans tracking seasons in realtime.
